Windows pyenv-win & Jupyter 개발 환경 구축 완벽 가이드

사내망 SSL 인증서 처리, pyenv-win 설치 및 기본 명령어, VS Code 연동 가이드

1. macOS vs Windows 환경 차이 및 사내망 인증서 등록

macOS에서는 brew install pyenv를 실행하지만, Windows 네이티브 환경에서는 Bash 기반의 원본 대신 Windows 전용 포크인 pyenv-win을 사용합니다.

사내망 SSL 오류 원인: 사내 방화벽/프록시 환경에서는 자체 루트 CA 인증서가 신뢰 저장소에 없으면 0x8a15005e(서버 인증서 불일치) 오류가 발생합니다.

사내 루트 CA 인증서 등록 (관리자 권한 PowerShell)

Import-Certificate -FilePath "C:\certs\LG-CNS-Root-CA.cer" -CertStoreLocation Cert:\LocalMachine\Root

실행 결과 화면에 Thumbprint와 Subject가 출력되면 정상적으로 등록된 것입니다.

2. pyenv-win 공식 설치 및 환경 변수 설정

공식 GitHub(pyenv/pyenv)에서 권장하는 원클릭 설치 스크립트를 실행합니다.

설치 스크립트 실행 (PowerShell)

Invoke-WebRequest -UseBasicParsing -Uri "https://raw.githubusercontent.com/pyenv-win/pyenv-win/master/pyenv-win/install-pyenv-win.ps1" -OutFile "./install-pyenv-win.ps1"; &"./install-pyenv-win.ps1"
Remove-Item ./install-pyenv-win.ps1

설치 후 확인 및 문제 해결

  • 스크립트 완료 후 열려 있는 PowerShell 창을 완전히 닫고 다시 실행합니다.
  • 만약 pyenv 명령어가 인식되지 않는다면 수동으로 환경 변수를 설정합니다:
[System.Environment]::SetEnvironmentVariable('PYENV', "$HOME\.pyenv\pyenv-win", 'User')
[System.Environment]::SetEnvironmentVariable('PYENV_ROOT', "$HOME\.pyenv\pyenv-win", 'User')
[System.Environment]::SetEnvironmentVariable('PYENV_HOME', "$HOME\.pyenv\pyenv-win", 'User')

$userPath = [System.Environment]::GetEnvironmentVariable('Path', 'User')
$pyenvPaths = "$HOME\.pyenv\pyenv-win\bin;$HOME\.pyenv\pyenv-win\shims"
[System.Environment]::SetEnvironmentVariable('Path', "$pyenvPaths;$userPath", 'User')

정상 확인 명령어: pyenv --version

3. pyenv 핵심 사용법 및 명령어 가이드

명령어 요약 표

명령어 용도 비고 / 윈도우 팁
pyenv install --list 설치 가능한 모든 파이썬 목록 확인 특정 버전 필터: | Select-String 3.14
pyenv install <버전> 특정 파이썬 버전 다운로드 및 설치 일반 64비트는 접미사 없는 버전 선택 (예: 3.14.5)
pyenv versions 로컬에 설치된 파이썬 버전 목록 조회 현재 활성화된 버전 옆에 * 표시
pyenv global <버전> 시스템 전체 기본 파이썬 버전 지정 %USERPROFILE%\.pyenv\pyenv-win\version에 저장됨
pyenv local <버전> 현재 작업 디렉터리 전용 버전 지정 해당 폴더에 .python-version 파일 생성됨
pyenv shell <버전> 현재 열려 있는 터미널 세션에만 임시 적용 환경 변수 PYENV_VERSION을 수정
pyenv rehash 실행 링크(shims) 파일 갱신 새 버전 설치 또는 pip 글로벌 실행 파일 설치 후 필수
pyenv uninstall <버전> 설치된 파이썬 버전 삭제 versions 디렉터리에서 해당 버전 폴더 제거

Python 3.14.5 설치 및 활성화 단계

# 1. 64비트 정식 버전 설치
pyenv install 3.14.5

# 2. shims 갱신
pyenv rehash

# 3. 글로벌 기본 버전 지정
pyenv global 3.14.5

# 4. 버전 확인
python --version

4. VS Code & Jupyter Notebook 연동

1) Python 인터프리터 선택

  1. VS Code에서 Ctrl + Shift + P (명령 팔레트)를 누릅니다.
  2. Python: Select Interpreter를 입력하고 실행합니다.
  3. 목록에서 Python 3.14.5 ('3.14.5': pyenv)를 선택합니다.

2) 새 Jupyter Notebook 파일 생성

  1. Ctrl + Shift + P를 누르고 Create: New Jupyter Notebook을 실행합니다.
  2. Untitled-1.ipynb 파일이 열립니다.

3) ipykernel 설치

VS Code 터미널(Ctrl + ~)에서 해당 환경에 ipykernel 패키지를 설치합니다.

# 일반 환경
python -m pip install ipykernel

# 사내망 SSL 인증서 지정이 필요한 경우
python -m pip install --cert "C:\certs\LG-CNS-Root-CA.cer" ipykernel

# shims 갱신
pyenv rehash

4) 노트북 커널 연결 및 동작 검증

노트북 우측 상단의 Select Kernel → Python Environments → Python 3.14.5를 선택한 뒤 첫 번째 코드 셀에서 실행합니다:

import sys
print("인터프리터 경로:", sys.executable)
print("파이썬 버전:", sys.version)

출력 결과의 경로가 .pyenv\pyenv-win\versions\3.14.5\python.exe로 나타나면 모든 구성이 정상 완료된 것입니다.
